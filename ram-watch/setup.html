Renderer footprints

The Windows companion reads the renderer's private memory counter, the same type of counter used by Chrome Task Manager. It runs for a short sample at most once a minute, then exits.

Use the monitored Chrome profile. Current Chrome versions require a separate profile for this connection. Your usual Chrome profile is not monitored by the companion. This uses your existing Chrome installation.
  1. Extract the complete RAM Watch package to a permanent folder.
  2. Run companion\Start-RAM-Watch.cmd. In that Chrome window, open chrome://extensions, enable Developer mode, choose Load unpacked, and select the package's ram-watch folder.
  3. Open Companion setup from RAM Watch's menu in that window. Copy its extension ID below.
  4. Run companion\Install.cmd and paste the ID. Installation is for your Windows user only.
  5. Click Enable renderer footprints below and allow the companion permission. Chrome grants debugger access when you load or re-enable the extension; that permission identifies tabs, and the extension does not attach a debugger to each tab.

Keep the overhead small

The helper is a native Windows executable, with no resident service, scheduled startup task, or extra language runtime. It keeps no trace files or measurement history. Samples are cached for a minute, including while the popup is open.

The launcher requests a 64 MiB browser disk cache and a 16 MiB media cache. These are cache targets, not a limit on all profile data: site storage, sign-ins, downloads, and other Chrome files can grow. Using this as your browsing profile avoids keeping duplicate Chrome sessions open.

What the number covers

A row shows its main renderer's private footprint. Related tabs can share a renderer; they are labeled as shared and that process is counted only once in the total. Browser, GPU, and separate iframe/worker processes are not added to each tab. Windows private footprint includes committed memory, so it is not a measurement of physically resident RAM alone.

Short tracing sessions identify the renderer PID; no screenshots, CPU profiles, memory dumps, or page scripts are collected by the helper. Another active Chrome profiler can prevent a sample; that tab will show as unavailable. Memory values change continuously, so comparisons with Task Manager should be taken at the same time.

Connection and removal

The browser connection listens on loopback with a randomly assigned port. Other software running as your Windows user may be able to control this monitored profile through that connection. Use the supplied launcher only for the profile you want to monitor.

Run companion\Uninstall.cmd to unregister and remove the helper. Your Chrome profile data is kept. Switching back to page estimates in the menu stops using the companion.
